# Первая пробная версия ведущего Лилы

Намерение фиксировано: «Почему я до сих пор курю?». Доска и броски прежние.

Ведущий может продолжить тему на одной клетке, отозваться на поправку и предложить следующий бросок, когда разговор исчерпан. Предложенный итог появляется в беседе; кнопка «Перейти к разбору мифов» принимает его. Новый разговор или поправка отменяют прежнее предложение, если ведущий не выдал обновлённый итог. Метрика заполненности анкеты больше не переключает этап.

Сведения для следующего этапа извлекаются отдельным запросом параллельно ответу ведущего. Это дополнительный расход API на текстовую реплику; при броске запрос извлечения пропускается. Ошибка извлечения сохраняет прежние данные и не отменяет ответ ведущего. Память содержит последние 15 пар дословно и резюме предыдущих, включая поправки и отвергнутые гипотезы.

## Локальный запуск

В `backend/.env` укажите `OPENAI_API_KEY` (см. `env.example`). Затем в двух терминалах запустите `npm run dev` из `backend` и `webapp`. Ключ не должен попадать в веб-клиент или Git. Модель задаётся прежним `OPENAI_MODEL`; эта версия не меняет модель автоматически.

## Проверка манеры ведения

Технические тесты не доказывают качество живого диалога. При пробной игре проверяйте:

1. «Не понимаю» — ведущий поясняет мысль, не отправляет автоматически бросать.
2. «Я уже не курил год и оставался собой» — пересматривает гипотезу потери идентичности, если выдвигал её.
3. «Не знаю» — не объявляет это сопротивлением и не требует признания.
4. «Идём дальше» — предлагает кубик, не удерживает новым вопросом.
5. «Мы это уже обсуждали» — признаёт повтор и меняет направление либо предлагает итог.
6. Поправка к итогу — прежняя кнопка перехода исчезает, если обновлённый итог ещё не готов.
7. Принятие итога — следующий этап использует согласованные наблюдения, а не отвергнутую трактовку.

Проверки: `npm test` в `backend` (Node с поддержкой experimental module mocks); `npm run build` и `npx tsc --noEmit` в `webapp`. API в тестах заменён заглушками, реальные запросы не отправляются.
