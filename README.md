# ZeroSmokeWay — Лабиринт

Браузерный квест о курении и свободе выбора, рассчитанный прежде всего на телефон в портретной ориентации. После выбора двери сразу начинается чат о выбранной теме. Игрок отвечает своими словами, обсуждает сомнения и затем открывает следующие двери. Отдельного второго этапа нет.

## Что работает

- 11 комнат, контекст из 34 тем для ведущего, выбор маршрута и финальный выход. Обсуждение каждого вопроса не гарантируется: игрок сам завершает разговор.
- Восемь атмосферных фонов, переходы, параллакс и процедурная музыка с разными настроениями комнат.
- Чат внутри каждой комнаты, собственные ответы, личные заметки, журнал и экспорт переписки.
- Сохранение на текущем устройстве через localStorage; продолжение после перезагрузки.
- Разговор с ведущим: AI при настроенном сервере и ограниченные авторские вопросы без ключа OpenAI.
- Отключение звука, громкость, уменьшение движения, клавиатурное управление диалогами.

Это первая игровая версия. Облачное сохранение и аккаунты в новом квесте пока не подключены. Работа без сети после закрытия вкладки не обещается: service worker пока нет. Эффективность продукта как помощи в отказе от курения требует отдельного исследования с участниками.

## Запуск

Нужен Node.js 22.18+ либо 24+. В двух терминалах:

```bash
cd backend
npm ci
npm start
```

```bash
cd webapp
npm ci
npm run dev
```

Открыть адрес Vite (обычно http://localhost:5173). Vite проксирует `/api` на `127.0.0.1:3000`. Сам квест работает без backend; при недоступном сервере чат показывает состояние отсутствия связи.

Для AI-диалога создать `backend/.env` и задать настоящий `OPENAI_API_KEY`. Не копировать демонстрационный ключ из примера как рабочий. `LABYRINTH_MODEL` необязателен, по умолчанию используется `gpt-4o-mini`. Ключ остаётся на сервере. Для отдельного API задать `VITE_API_BASE_URL` в `webapp/.env`.

При разговоре с ведущим на сервер передаются сообщение, история этой комнаты и личные заметки. Обычное прохождение сохраняется локально и не требует отправки ответов на сервер.

## Устройство проекта

- `webapp/src/game/` — React-интерфейс, содержание комнат, сохранение и музыка; Phaser 3 загружается отдельным модулем для сцены.
- `webapp/public/game/` — оптимизированные WebP-фоны. Оригинальные иллюстрации созданы через imagegen; промпты и происхождение — [docs/art/generated-assets.json](docs/art/generated-assets.json).
- `backend/services/labyrinthService.js` — ограниченный контекст ведущего и авторский fallback.
- `backend/routes/labyrinth.js` и `api/labyrinth.js` — локальный Express и Vercel endpoint.
- `frontend/` и прежние маршруты backend — предыдущая версия, не участвуют в новом игровом интерфейсе.
