# ZeroSmokeWay — Лабиринт

Браузерная игра о курении, рассчитанная на телефон. Перед первой дверью — введение и три кнопки: «Мне нравится», «Помогает расслабиться», «Моя причина». Выбранная причина становится началом разговора.

В комнатах игрок записывает один перекур, разбирает его на действия и сравнивает с другим случаем. Чат открыт сразу после двери. Прогресс зависит от действий игрока; при сбое AI доступны явно обозначенные подсказки и ручной ввод. После первого сохранения можно выйти к своим записям.

## Запуск

Node.js 22.18+ или 24+. В двух терминалах:

```bash
npm ci --prefix backend
npm start --prefix backend
```

```bash
npm ci --prefix webapp
npm run dev --prefix webapp
```

Открыть адрес Vite, обычно http://localhost:5173. Он проксирует `/api/labyrinth` на localhost:3000. Также можно использовать `./start-local.sh` после установки зависимостей.

Ключ хранится в `backend/.env`: `OPENAI_API_KEY`. Необязательный `LABYRINTH_MODEL` задаёт модель, по умолчанию gpt-4o-mini. Пример без ключа — backend/env.example. При разговоре на сервер передаются сообщение, история комнаты и контекст записей.

## Проверки

```bash
npm test --prefix webapp
npm run build --prefix webapp
npm test --prefix backend
```

## Структура

- `webapp/src/game/` — единственный игровой интерфейс, состояние, сцены и музыка.
- `backend/services/labyrinthService.js` — ведущий; `backend/api/labyrinth.js` — общий API-обработчик.
- `api/labyrinth.js` — вход Vercel; vercel.json собирает webapp/dist.
- `docs/design/` — дизайн и описание реализованного; `docs/archive/` — исторические материалы.
- `knowledge-base/` — исходные материалы, не отдельное приложение.

Старые Flutter-приложение, чат с кубиком, альтернативный Лабиринт и их API удалены. Их код доступен в Git. Сохранённые ключи localStorage не удаляются; текущий путь использует `zsw_three_rooms_v1`. Нет аккаунтов, облачной синхронизации и service worker. Эффективность для отказа от курения пока не проверена на участниках.
