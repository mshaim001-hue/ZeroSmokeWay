# Постановка браузерной игры

Основной экран — телефон в портретной ориентации. Основной текст 17 px, пояснения от 16 px. За текстом тёмная подложка с непрозрачностью 79%; иллюстрация остаётся видимой.

Фоны находятся в webapp/public/game, Phaser добавляет атмосферу, UI использует доступные HTML-кнопки. Музыка запускается после действия пользователя; звук отключается. Учитывается reduced motion и высота visualViewport при клавиатуре.

Текущий продукт содержит три комнаты с одной переносимой историей. Старые приложения удалены из рабочего дерева.
