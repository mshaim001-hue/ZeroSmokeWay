# Постановка браузерной игры

Основной экран — телефон в портретной ориентации. Основной текст 17 px, пояснения 16 px. Под текстом тёмная полупрозрачная подложка; иллюстрация остаётся видимой.

Phaser активно обрабатывает предметы и двери, рисует разные композиции для комнат. Существенные действия повторены HTML-кнопками. Карта интерактивна, пройденные двери светятся. Восемь фонов находятся в webapp/public/game; двенадцать игровых сцен используют их вместе с собственными объектами и геометрией.

Порог + десять тематических комнат + выход. Музыка оригинальная, генерируется Web Audio; каждая тема имеет свою партитуру. Запуск после жеста пользователя, mute и громкость доступны. Учитываются reduced motion, сворачивание вкладки и visualViewport при клавиатуре.

Старый трёхкомнатный интерфейс удалён, данные мигрируют. Облака нет. Продолжительность и эффект на отказ не подтверждены испытанием с людьми.
