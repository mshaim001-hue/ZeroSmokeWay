# Музыка полного лабиринта

Оригинальная процедурная музыка в Web Audio, без сторонних файлов и сетевых загрузок. У порога и каждой из десяти тем — свой восьмитактовый мотив из нот и пауз; у выхода светлый мотив. Общие фоновые аккорды связывают путешествие, но регистр, фильтр, темп и интервалы отличаются.

| Комната | Музыкальная подача |
|---|---|
| Коридор / порог | Низкая открытая тема, паузы, ожидание |
| Удовольствие | Тёплая мажорная последовательность |
| Напряжение | Нижний регистр, сдержанное повторение секунды |
| Начало | Спускающийся мотив, длинные паузы |
| Компания | Тёплое движение с терцией |
| Ритуал | Регулярное чередование тонов |
| Петля | Повторяющийся минорный рисунок |
| Цена | Редкий пульс и незавершённое движение |
| Завтра | Повтор одной ноты, постепенно меняющийся интервал |
| Страх трудностей | Медленные открытые интервалы |
| Мир / упаковка | Неустойчивая последовательность |
| Выход | Более светлая терция и верхняя октава |

Три тихих pad-осциллятора, фильтр, небольшой шум, мелодические ноты и мягкое эхо. Смена комнаты плавно перекрывает слои за 2,4 секунды. Продвижение слегка меняет уровень мелодии. Осмотр, действие, дверь и завершение имеют отдельные звуковые отклики.

Громкость по умолчанию 35%, mute и slider в интерфейсе. AudioContext создаётся после жеста; при сворачивании приостанавливается. Reduced motion уменьшает плотность и шум. destroy останавливает источники, таймеры, отключает узлы и закрывает контекст. Phaser audio отключён, чтобы не создавать вторую звуковую систему.

Процедурный саундтрек проверяется на запуск и управление технически. Оценка качества звучания реальными игроками ещё не проводилась. Озвучивания реплик нет.
