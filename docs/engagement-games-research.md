# Ресерч: успешные игры с похожей динамикой (не про курение)

Дата: 4 октября 2026. Статус: кабинетный обзор по открытым источникам (GDC, интервью разработчиков, академические разборы, кейсы продаж). Это не систематический обзор рынка и не доказательство переноса на отказ от курения.

## Зачем этот документ

Интерес проекта — не «какие игры про привычки», а **динамика, напряжение, ощущение и то, что заставляет хотеть играть**. Ниже — успешные примеры вне темы курения, сгруппированные по типу тяги, а не по жанру.

Критерий «успеха»: заметный критический и/или коммерческий результат (награды, продажи, устойчивая репутация). Критерий «похожести»: хотя бы один из двигателей Лабиринта — любопытство, разговор как действие, личный смысл, повтор с новым смыслом, ощущение, что мир/ведущий тебя помнит.

## Сводка: какие двигатели работают

| Двигатель «хочу играть» | Как проявляется | Сильные примеры |
|---|---|---|
| Любопытство как прогресс | Знание = награда; следующий вопрос рождается из прошлого открытия | Outer Wilds, Return of the Obra Dinn, Her Story |
| Микро-реактивность | Игра замечает мелкий выбор; ощущение «меня слышат» | Disco Elysium, Hades |
| Повтор без пустоты | Смерть/возврат даёт новый слой истории, не стирает смысл | Hades |
| Символическое проживание | Действие = метафора внутреннего процесса | Celeste, Spiritfarer, Papo & Yo |
| Тихая личная история через объекты/ощущения | Минимум текста, максимум узнавания | Unpacking, Florence, Gris, Before Your Eyes |
| Сборка смысла самим игроком | Игра не выдаёт вердикт; игрок строит теорию | Her Story, Obra Dinn, Outer Wilds |

## 1. Любопытство как единственный двигатель

### Outer Wilds (Mobius Digital, 2019)

**Успех:** культовый статус; GDC-разборы дизайна; эталон curiosity-driven exploration.

**Что тянет играть:** нет квестов, XP, апгрейдов как основной награды. Награда — знание. Открытие перекрашивает уже знакомое место и ставит следующий вопрос.

**Динамика:** вопрос → исследование → знание → новый вопрос. Игрок сам формулирует цель.

**Урок для Лабиринта:** дверь должна обещать *вопрос*, который игрок уже почти задал себе, а не «тему для разговора». После комнаты знакомый коридор должен чуть иначе читаться (новые двери, своя формулировка, видимая петля).

Источники: [GDC Beachum, 2021](https://media.gdcvault.com/GDC%2B2021/beachum_gdc_2021%281%29.pdf); [тезис Beachum](https://sbekumod.github.io/Assets/OWtesi.pdf).

### Return of the Obra Dinn (Lucas Pope, 2018)

**Успех:** высокий критический приём; сильная репутация среди «думающих» игр; устойчивые продажи (оценки третьих сторон — порядка миллиона+ копий на Steam в ряде датасетов).

**Что тянет играть:** напряжение дедукции + редкие «щелчки» подтверждения. Можно ошибаться и продолжать; позднее знание делает ранние сцены яснее.

**Динамика:** фрагмент → гипотеза → проверка → частичное подтверждение → новая гипотеза.

**Урок:** прогресс не обязан быть «комната пройдена». Достаточно «три куска сложились» (у вас уже близко: четыре свидетельства). Важен ритм: не всё подтверждается сразу.

### Her Story (Sam Barlow, 2015)

**Успех:** IGF Grand Prize, Excellence in Narrative; BAFTA и другие награды; коммерческий прорыв для экспериментальной narrative-игры.

**Что тянет играть:** поиск по словам + воображение игрока как «движок». История собирается нелинейно; игрок ведёт заметки и теории.

**Динамика:** ключевое слово → клип → новые слова → сдвиг теории.

**Урок:** свобода формулировки (у вас — свободный чат) сильна, когда из ответа рождается *следующий ход*, видимый игроку. У Barlow поиск — механика. У Лабиринта нужно явное «что открылось / куда это ведёт», иначе чат ощущается анкетой.

Источники: [IGF 2016](https://igf.com/article/her-story-takes-home-top-honors-18th-annual-igf-awards); [GDC / Game Developer про воображение игрока](https://www.gamedeveloper.com/design/video-making-i-her-story-i-and-using-the-player-s-imagination-as-a-narrative-tool).

## 2. Разговор, который хочется продолжать

### Disco Elysium (ZA/UM, 2019)

**Успех:** The Game Awards (Narrative и др.); культурный феномен dialogue-RPG без классического боя.

**Что тянет играть:**
- диалог — основное действие, не обёртка квеста;
- **micro-reactivity**: игра помнит мелочи и отвечает на них (по словам Justin Keenan — тысячи таких откликов);
- «бессмысленные» ветки делают мир живым: разговор ценен сам по себе, не только как путь к XP;
- fail-forward: провал проверки часто даёт другую интересную сцену.

**Динамика:** сказал что-то своё → мир/внутренние голоса откликнулись → захотелось проверить другую сторону себя.

**Урок для Лабиринта (самый близкий по форме):** AI-ведущий уже может давать реактивность. Критично, чтобы игрок *видел*, что его формулировку вернули: цитата в заметке, дверь названа его словами, следующий вопрос строится из его эпизода. Keenan: когда micro-reactivity работает, это ощущение хорошего мастера за столом.

Источники: [Game Developer / Keenan](https://www.gamedeveloper.com/business/understanding-the-meaningless-micro-reactive-and-marvellous-writing-of-i-disco-elysium-i-); [разбор Keenan](https://ikesau.co/justin-keenan-meaningless-choices-and-impractical-advice/).

### Hades (Supergiant, 2020)

**Успех:** коммерческий и критический хит; эталон «каждый забег считается».

**Что тянет играть:** повтор не пустой. Смерть → хаб → новый диалог / отношения / знание. Mantra команды: every run counts. Реактивность персонажей к оружию, провалам, повторам боссов. Намеренно без daily-login addiction; удержание через желание увидеть персонажей и историю.

**Динамика:** действие → возврат → мир помнит → новая реплика → снова в путь.

**Урок:** сессии Лабиринта (сохранил путь, вернулся) должны ощущаться как «продолжение отношений с ведущим и с собой», а не как «дозаполнить анкету». Даже короткий возврат — новая реплика про прошлую комнату.

Источники: [Tom's Guide / Kasavin](https://www.tomsguide.com/features/hades-exclusive-interview-supergiant); [Game Developer про narrative rewards](https://www.gamedeveloper.com/design/how-supergiant-weaves-narrative-rewards-into-i-hades-i-cycle-of-perpetual-death).

## 3. Напряжение и ощущение через символ

### Celeste (Maddy Makes Games, 2018)

**Успех:** культовый indie; сильное сообщество; Assist Mode как этический дизайн сложности.

**Что тянет играть:** механика = метафора. Смерть reframed как обучение; внутренняя «плохая» часть не уничтожается, а интегрируется. Паника проживается через управление (дыхательный мини-игровой момент).

**Динамика:** трудно → чуть получилось → узнавание своего паттерна → желание следующую полку.

**Урок:** не копировать платформер. Копировать принцип: **ощущение борьбы должно быть в действии**, не только в тексте. Для Лабиринта — момент, где игрок *сравнивает* ожидание и факт руками (два столбца, перемотка сцены, выбор «что было до / после»), а не только обсуждает это словами.

Источники: [Kotaku](https://kotaku.com/celeste-taught-fans-and-its-own-creator-to-take-better-1825305692); [PlayLab Tampere](https://blogs.tuni.fi/playlab/game-research-highlights/when-psychology-meets-game-design-the-case-of-celeste/).

### Spiritfarer (Thunder Lotus, 2020)

**Успех:** коммерчески заметный cozy-hit; академические разборы как serious/transformational game про горе и прощание.

**Что тянет играть:** забота + неизбежное прощание. Ритуал Everdoor создаёт напряжение даже в «мягкой» эстетике. Исследования фиксируют рефлексию о смертности, эмпатию, изменение взгляда у части игроков — без обещания терапии.

**Динамика:** привязался → служил → отпустил → пустота/тепло → следующий пассажир.

**Урок:** финальная комната «Свобода» сильнее, если до неё были маленькие ритуалы отпускания (заметка, закрытие двери, возврат своей фразы), а не только чеклист из 10 тем.

Источники: [ETR&D / Unlocking the Everdoor](https://link.springer.com/article/10.1007/s11423-024-10357-x); [диплом UT про mortality reflection](https://essay.utwente.nl/fileshare/file/106630/vanderWee_MA_BMS.pdf).

### Papo & Yo (Minority Media)

**Успех:** не блокбастер продаж, но важный кейс existential/transformational design в академической литературе.

**Что даёт:** символическое проживание травмы (монстр = алкоголизм отца) через действие и ритуал освобождения. Игроки могут пережить сильный аффект; авторам важен пост-игровой разбор.

**Урок:** сильный символ работает, если игрок *делает* жест освобождения, а не только соглашается с тезисом. Осторожно с интенсивностью и поддержкой после.

Источник: [Frontiers, Rusch & Phelps, 2020](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2020.571522/full).

## 4. Короткие эмоциональные игры: доказательство спроса

Эти игры показывают: взрослые платят за ощущение и личный смысл без «геймификации привычек».

| Игра | Ощущение / напряжение | Маркер успеха |
|---|---|---|
| **Florence** | Дуга отношений через касания и мини-действия; коротко, лично | Сильный критический приём; эталон short-form emotional play |
| **Gris** | Горе через цвет, движение, пространство | >1 млн копий (к 2020) |
| **Unpacking** | Жизнь через вещи; тихий «детектив о себе» | >1.2 млн на Steam; BAFTA Best Narrative; EE GotY (публичное голосование) |
| **Before Your Eyes** | Время/моргание как ставка; жизнь вспышками | Награды + дистрибуция (в т.ч. Netflix Games); оценки продаж расходятся по источникам |
| **Journey** | Связь без слов; совместный путь | Классика; культурный эталон «ощущения» |

Источники: [Gris 1M+](https://www.gamedaily.biz/indie-title-gris-has-sold-more-than-one-million-copies/); [Unpacking case study](https://screencurrency.screenaustralia.gov.au/wp-content/uploads/2026/05/Unpacking-Screen-Currency-2026-Case-Study.pdf).

**Урок:** Лабиринту не обязателен боевой луп. Обязательны **атмосфера комнаты, ритм, тактильный/визуальный сдвиг после шага** и ощущение, что это *моя* история, даже если структура общая.

## 5. Что из этого ближе всего ZeroSmokeWay / Лабиринту

Близость по форме (не по теме):

1. **Disco Elysium** — разговор как игра + память о выборе.  
2. **Outer Wilds / Her Story / Obra Dinn** — знание и своя теория как прогресс.  
3. **Hades** — возврат в сессию с новым смыслом.  
4. **Celeste / Spiritfarer** — внутренний процесс через действие и ритуал.  
5. **Unpacking / Florence** — взрослая аудитория, короткий/средний опыт, личное без морализаторства.

Далеко по форме, но полезно по ощущению: Journey, Gris (атмосфера и дуга без давления «согласись»).

## 6. Паттерны успеха → гипотезы для Лабиринта

| Паттерн из успешных игр | Гипотеза для продукта |
|---|---|
| Знание/инсайт как лут | После комнаты показывать *одно* конкретное открытие игрока, не саммари бота |
| Micro-reactivity | Возвращать цитату игрока в дверях, заметках, финале «Свобода» |
| Every session counts | При возврате — реплика про прошлую комнату, не общий greeting |
| Игрок строит теорию | Дать место для собственной модели («как у меня это связано»), не только ответы на вопросы |
| Ритуал перехода | Короткий жест закрытия комнаты / выбора следующей двери с ощутимым сдвигом фона/звука |
| Fail-forward | Сомнение и «не согласен» открывают ветку, а не тормозят прогресс (у вас частично уже так) |
| Напряжение в структуре | Двери с разной «ценой» (легче / больнее / ближе к моей причине), не три равноценные плитки |

## 7. Ограничения ресерча

- «Успех» ≠ «изменил поведение в жизни». Spiritfarer и Celeste меняют переживание и рефлексию у части игроков; это не RCT отказа от курения.
- Перенос механик 1:1 невозможен и не нужен. Нужен перенос **двигателя желания играть**.
- Академические работы по transformational games часто основаны на малых выборках и самоотчётах.
- Продажи indie часто оцениваются косвенно; цифры — ориентиры порядка, не аудит.

## 8. Практический вывод

Рынок уже доказал спрос на игры, где хочется продолжать из‑за:

- **недосказанности и своей гипотезы** (Her Story, Obra Dinn, Outer Wilds);
- **ощущения, что тебя помнят** (Disco, Hades);
- **символа, который проживаешь телом/действием** (Celeste, Spiritfarer);
- **тихой личной точности** (Unpacking, Florence).

Для Лабиринта главный разрыв с этими хитами сейчас не в теме курения, а в том, **насколько напряжение и награда живут в правилах и обратной связи**, а не только в качестве текста AI.

## Следующий шаг (если продолжать)

Выбрать 2–3 эталона (рекомендация: Disco + Outer Wilds/Her Story + Hades) и сделать короткий design audit текущего playflow: где двигатель есть, где проседает, какой минимальный прототип усиливает одно ощущение за сессию.
