# Проверка актуальной диалоговой версии

Текущая механика: дверь сразу открывает чат внутри комнаты. Обязательные задания и карточки не участвуют в прохождении. Проверены в интерфейсе открытие следующей двери, отправка сообщения, ответ сервера в авторском режиме, завершение разговора и переход к следующей теме. Экспорт переписки проверяется тестом.

## Проверки кода

- Backend: 58 тестов, включая ограничения API, передачу темы выбранной двери и истории в AI, отсутствие подмены системной роли и fallback.
- Webapp: 7 тестов — тематические данные, достижимость выхода, восстановление пути, валидация сохранений, экспорт ответов и переписки.
- TypeScript и Vite production build проходят; крупный модуль Phaser остаётся отдельной динамической загрузкой.

`docs/qa/playthrough.js` обновлён под новый диалоговый ход. Он отправляет синтетические сообщения и предназначен для отдельного тестового браузера. Полный новый UI-маршрут этим скриптом пока не прогонялся. Прошлый проход 11 комнат с заданиями не считается проверкой нового хода.

## Реальные ограничения

Рабочий ключ OpenAI требуется для ответов по смыслу сообщения. Авторские вопросы без ключа не являются живым AI-диалогом. В этой проверке живое качество AI не оценено. Требуются реальный iPhone/Android, экранная клавиатура и замеры слабых устройств. Нет облачного сохранения, service worker и исследования эффективности.

Скриншоты находятся локально в игнорируемом `output/playwright/`. Архив прежней концепции находится в `docs/archive/labyrinth-v1/` и не является актуальным обещанием продукта.
