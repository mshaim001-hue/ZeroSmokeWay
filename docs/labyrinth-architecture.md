# Архитектура Лабиринта

Один браузерный интерфейс: React + TypeScript + Phaser 3 + Web Audio.

- `LabyrinthApp.tsx`: вход, чат, управление сценой, карта и журнал.
- `rooms.ts`: порог, десять тем и выход; предметы, реплики, действия, соседство дверей.
- `gameState.ts`: единственная система прогресса, сохранение, миграция и экспорт.
- `PhaserStage.tsx`: интерактивные предметы, карта, визуальные изменения.
- `audio.ts`: оригинальные комнатные музыкальные темы и отклики действий.
- `api.ts`: только разговор, без системы оценки готовности.

Ключ хранится в backend/.env. Express и Vercel используют один backend/api/labyrinth.js. API возвращает response/mode/issue, без evidence/ready. Переписка и действия сохраняются локально. Сбой AI не блокирует комнату.
