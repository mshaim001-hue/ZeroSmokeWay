# Архитектура Лабиринта

Один браузерный интерфейс: React + TypeScript, Phaser 3 для окружения, Web Audio для музыки.

`PrototypeApp.tsx` — комнаты и чат, `prototypeState.ts` — сохранение и правила, `api.ts` — диалог с сервером. Вход предлагает три причины: удовольствие, расслабление, своя формулировка. Все они начинают разбор одного перекура; выбранная причина передаётся ведущему.

Локальный Express и функция Vercel используют один обработчик `backend/api/labyrinth.js`. Единственный игровой endpoint — `/api/labyrinth`. Ключ остаётся в backend/.env.

Сохранение `zsw_three_rooms_v1` дополняется initialReason; старые записи этого формата читаются без причины. Старые ключи localStorage не удаляются. Старый интерфейс и API удалены из рабочего дерева; они доступны в истории Git.
