# Проверка трёхкомнатного прототипа

4 октября 2026. Проверка разработчиком на синтетических примерах, не исследование эффективности.

## Автоматические проверки

- Webapp: 17 тестов (10 прежних и 7 новых) проходят.
- TypeScript и production Vite build проходят. Сохраняется предупреждение о размере Phaser-чанка, загружаемого отдельно.
- Новые тесты: открытие от действия, неопределённость, оба порядка комнат, несогласие, сохранение версий, восстановление/повреждённый JSON и персональный контекст.

## В браузере

Использована CUA, отдельный localhost:5174, экран 390 × 844. Старое сохранение на основном origin не изменялось.

1. Начальный экран → первая дверь: чат открывается сразу.
2. На явно вымышленную тестовую реплику пришёл ответ живого AI.
3. В «Звонке» вручную собраны два события, отмечен момент, заполнены ожидание и наблюдение. Открылись две комнаты и выход.
4. «Разделение» подхватило личный момент. Выбраны составляющие, сохранена пауза и собственный вопрос.
5. «Повторение» подхватило первую историю и составляющие. Добавлен второй тестовый случай, выбрано различие, сохранена собственная версия.
6. При возвращении в «Звонок» показаны сохранённая лента, составляющие и другой случай.
7. Финал восстановился после перезагрузки с личными данными.
8. Мобильный снимок: output/playwright/prototype-mobile.jpg (игнорируемый тестовый артефакт).

## Недоступность API

Отдельный Vite на localhost:5180 с VITE_API_BASE_URL=http://127.0.0.1:1. Пользовательский .env и backend не менялись.

Запрос завершился ошибкой; пользовательский ответ остался в чате. Видны предупреждение, повтор запроса и авторская подсказка с явной подписью «БЕЗ AI». Через ручные действия сохранён эпизод с неопределённостью, получено открытие, открыт зал выхода. API не блокирует прогресс.

Тестовый сервер 5180 остановлен после проверки. Основной прототип открыт для пользователя отдельно от тестовых прохождений.

## Что не проверено

Реальные интервью и желание возвращаться, отказ от курения, iOS/Android на физических устройствах, облачное сохранение. Автоматическое извлечение событий из беседы пока отсутствует; текущий сценарий использует ручной ввод в сцене. Большие кинематографические реакции на каждое действие не реализованы.

## После объединения продукта

Выбор причины возвращён; первой комнатой стал «Перекур», без обязательного звонка. Старые интерфейсы и API удалены, их код доступен в Git. Текущие проверки: 8 webapp тестов, 14 backend тестов и production build. Фон под текстом — 79% непрозрачности, основной текст 17 px. Новые причины проверены тестом на открывающую реплику и совместимость старого сохранения.
