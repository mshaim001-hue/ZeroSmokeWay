# Лабиринт: спецификация производства

Версия 1. 3 октября 2026. Браузерный квест, телефон — основная платформа. Phaser 3.90 + TypeScript, React для доступного текстового интерфейса, существующий Node API для дополнительного AI-диалога. Это законченный авторский маршрут с опциональным AI, а не доказанная терапия.

## Переживание и визуальная система

Камерный психологический квест: неизвестность → узнавание → исследование → собственный выбор → выход. Без кубиков, карты, очков согласия, таймера выживания и скримеров. Игрок управляет темпом и может оспаривать ведущего. Цель помощи с курением обозначена открыто.

Портретная камера первого лица. Тёмная кинематографичная архитектура, натуральные материалы, плёночное зерно, прохладные тени и точечный янтарный свет. Комната занимает весь экран. Типографика: крупный спокойный serif для заголовков, читаемый sans для диалога, monospace для номеров помещений. Цвет активного действия — приглушённый янтарь. Финал светлый, но не ослепляющий.

Вход: логотип/название «ЛАБИРИНТ», строка «У каждой привычки есть выход», короткое описание, кнопки начала и продолжения, звук и настройки. После начала — коридор, вопрос и три двери. Интерфейс основного прохождения: верхняя строка возврата/номер/настройки, заголовок комнаты, интерактивная сцена, нижняя панель текущего действия. Кнопки минимум 44 px. Все значимые действия доступны HTML-кнопками: Canvas не единственный способ пройти игру.

## Арт — фиксированные окружения до генерации

Общий формат исходников: portrait 2:3, камера на уровне глаз, центральная перспектива, без людей, текста, сигарет крупным планом и UI внутри картинки. Низ изображения тёмный/спокойный, оставляет пространство под панель. Изображения идут в webapp/public/game; оптимизированные webp для runtime, оригиналы и промпты сохраняются в документации/каталоге ассетов.

## Переходы

Нажатие двери → её выделение и низкий звуковой отклик → затемнение 350 ms → загрузка следующего окружения → проявление 550 ms → заголовок → действие. Запрещено принимать повторное нажатие во время перехода. Если изображение не загрузилось, остаётся атмосферный градиент и весь доступный интерфейс. Reduced motion: короткое растворение без параллакса/частиц. На открытие смысла — тихий трёхнотный мотив и изменение света, без вспышки.

Основной цикл комнаты: выбрать/осмотреть объект → пройти авторские вопросы и действия → кратко записать собственную мысль (можно пропустить) → открыть следующие двери. Разговор с AI доступен отдельно внутри комнаты и не блокирует прохождение. Персонаж не заставляет признать тезис ради выхода.

## Музыка

Оригинальный Web Audio ambient: общая тема D–A–E, отдельный профиль каждого окружения, перекрёстное затухание ~2 секунды. Звук только после жеста, mute и volume сохраняются. Во время диалога музыка остаётся тихой. При скрытии вкладки звук и анимация приостанавливаются. Детали — labyrinth-audio.md.

## Состояние и сохранение

Версионированное локальное сохранение: текущая комната, пройденные комнаты, ответы по событиям, личные записи, найденные предметы, диалог, звук и дата изменения. Сохранение после каждого действия. Ошибка localStorage не мешает игре, показывается честный статус. Продолжить/начать заново, подтверждение сброса, экспорт личного результата. Серверные диалоги — optional; нельзя обещать облачное сохранение без конфигурации и реализованной синхронизации.

## Производительность и адаптация

Сцена Phaser занимает viewport, React overlay использует 100dvh и safe-area. Никакой обязательной горизонтальной ориентации. Клавиатура: чат прокручивается, ввод остаётся доступен, сцена за панелью не принимает нажатия. Активное окружение грузится по потребности; первая картинка должна быть компактной, остальные не блокируют вход. Phaser resolution ограничена для мобильного GPU. В фоновом состоянии game loop паузится. Музыка не требует загрузки файлов. Lazy import Phaser.

## Проверки при сдаче

TypeScript, production build, backend tests. Браузер: 390×844 и 360×740, desktop, touch, прохождение от старта до финала, собственный ответ, возврат, перезагрузка/продолжение, настройки/звук, чат при отсутствии API, отсутствие горизонтального overflow, reduced motion. Скриншоты и отчёт сохраняются. Публикация не обязательна: локальный preview и проверенный build — результат текущей задачи.
